# スーパー・ジャンプアドベンチャー 🍄

スーパーマリオ風の2Dプラットフォーマーゲーム。HTML5 Canvas と素のJavaScriptだけで作られた、ビルド不要・依存ゼロのWebアプリです。

## あそびかた

`mario/index.html` をブラウザで開くだけ。インストールやサーバーは不要です。

### 操作

| 操作 | キー |
|------|------|
| 移動 | `←` `→` または `A` `D` |
| ジャンプ | `スペース` / `↑` / `W` |
| リスタート | `Enter` |

スマホ・タブレットでは画面下の操作ボタンが自動で表示されます。

### ルール

- コインを集めてスコアを稼ごう（🪙 +50、`?`ブロック +200）
- 敵（クリボー風）は**上から踏む**と倒せる（+100）。横から当たるとダメージ
- 穴に落ちたり敵に当たると残機が減る（残機3）
- 右端の**ゴール旗**に触れるとクリア！

## 特徴

- 重力・加速・摩擦のある物理挙動と、X/Y軸を分離したAABB当たり判定
- スクロールするカメラ、雲・丘のパララックス背景
- `?`ブロック、レンガ、コイン、踏みつけで倒せる敵、ゴール旗
- キーボード操作 + モバイルのタッチ操作対応
- レスポンシブ表示（画面サイズに合わせて拡大縮小）

## ファイル構成

```
mario/
├── index.html   # 画面レイアウト・各種オーバーレイ
├── style.css    # スタイル（背景・HUD・タッチUI）
└── game.js      # ゲーム本体（物理・当たり判定・描画・レベル）
```

## レベルの編集

`game.js` 内の `LEVEL` 配列（文字のグリッド）を書き換えるとステージを変更できます。

| 文字 | 意味 |
|------|------|
| `X` | 地面 |
| `B` | レンガ |
| `?` | コインブロック |
| `C` | コイン |
| `E` | 敵 |
| `G` | ゴール旗 |
| `P` | プレイヤー開始位置 |
| (空白) | 何もなし |
